# IA-03 · Sistema Baseado em Conhecimento: empréstimo de livros

Sistema baseado em conhecimento que decide se um aluno pode levar um livro emprestado da biblioteca universitária.

## O que foi feito

- Base de fatos inicial (F1 a F8) e cinco regras SE…ENTÃO encadeadas (R1 a R5).
- Encadeamento progressivo (dirigido por dados) e encadeamento regressivo (prova de um objetivo, com rastreamento).
- Classificação do tipo de raciocínio: dedução, comparada com indução e abdução no mesmo cenário.
