# GI-04 · Meu repositório acadêmico no GitHub

É este repositório. A atividade pede um portfólio acadêmico organizado no GitHub aplicando os conceitos de arquitetura da informação vistos na aula.

## O que foi feito

- Classificação: hierarquia de período, matéria e atividade.
- Taxonomia: vocabulário controlado de matéria, tipo, tema, tecnologia, autoria e status.
- Metadados: cabeçalho YAML em cada atividade e um catálogo em CSV.
- Navegação: README inicial, trilha no topo de cada página e links de anterior e próxima.
- Encontrabilidade: IDs únicos, nomes padronizados e índices por tema, tipo e tecnologia.
- Relações entre conteúdos: campo `relacionados`, seção "Relacionado com" e um mapa.
