# GI-01 · Qualidade da informação: informação boa ou informação ruim?

Classifiquei 8 situações de uma empresa como informação adequada ou informação com problema e, nas problemáticas, respondi qual é o problema, qual pode ser o impacto e como melhorar.

## O que foi feito

- Adequadas: relatório de vendas atualizado ontem, dashboard atualizado automaticamente e manual atualizado disponível para toda a equipe.
- Com problema: lista de clientes de três anos atrás (desatualizada), planilha financeira sem responsável, relatório com dados diferentes do sistema (contraditória), senhas visíveis para todos os funcionários (insegura) e documento salvo só no computador de um funcionário (dependente de uma pessoa).
- Nas soluções aparecem revisão periódica com responsável definido, fonte única da informação, controle de acesso (com a LGPD em vista) e armazenamento compartilhado com backup.
