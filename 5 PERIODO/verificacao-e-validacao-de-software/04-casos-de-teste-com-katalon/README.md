# VV-04 · Casos de teste automatizados com Katalon Recorder

Cinco casos de teste criados e executados no Katalon Studio (Record Web) contra o OrangeHRM, com as evidências de execução. Resultado: 5 de 5 aprovados.

## O que foi feito

- TC01, login válido, 6 passos aprovados.
- TC02, login inválido, 5 passos aprovados.
- TC03, buscar funcionário no módulo PIM, 9 passos aprovados.
- TC04, adicionar funcionário no PIM, 10 passos aprovados.
- TC05, logout, 7 passos aprovados.
