# HT-06 · Mapa de Machine Learning: os 4 tipos e os algoritmos

Mapa completo de machine learning, organizando os quatro tipos de aprendizado, os problemas que cada um resolve e os algoritmos principais com a função de cada um.

## O que foi feito

- Supervisionado: classificação e regressão, com regressão linear e logística, árvore de decisão, random forest, KNN, SVM, Naive Bayes e redes neurais.
- Os demais tipos de aprendizado e seus algoritmos, sempre com um exemplo de uso.
