# Convenções de nomes

| O quê | Regra | Exemplo |
|---|---|---|
| Pasta de período | `N-periodo` | `5-periodo/` |
| Pasta de matéria | slug da matéria | `eletiva-3-ia/` |
| Pasta de atividade | `NN-nome-curto`, número na ordem da matéria | `04-prolog-biblioteca/` |
| ID da atividade | sigla da matéria + número com 2 dígitos | `IA-04` |
| Arquivos | minúsculas, sem acento, palavras separadas por hífen | `atividade-prolog-biblioteca.docx` |
| Código Java | mantém o nome da classe, porque o Java exige | `AgenteVigia.java` |
| Arquivo que a ferramenta espera com certo nome | mantém o nome original | `login_data.json` (massa de dados do Katalon) |
| Versões | sufixo `-v2`, `-v3` quando precisar guardar a anterior | `relatorio-final-v2.docx` |
| Commits | `ID: o que mudou` (verbo no presente) | `IA-04: adiciona implementação em Prolog` |

Siglas dos IDs: IA (Eletiva III – Inteligência Artificial), EXT (Unidade de Extensão – Full Stack), VV (Verificação e Validação de Software), GI (Eletiva IV – Gestão da Informação), GOV (Governança em Tecnologia da Informação), HT (High Tech Aplicada ao Mercado), TE (Tech English) e EMP (Empreendedorismo e Plano de Negócios). As outras entram conforme as matérias forem adicionadas.
