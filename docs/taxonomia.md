# Taxonomia

Vocabulário controlado do repositório. Nos metadados, só uso termos desta página, sempre no formato **slug** (minúsculas, sem acento, com hífen).

## 1. Período (`semestre`)

Número do semestre: `5`, `6`... A pasta é `N-periodo`.

## 3. Tipo de entregável (`tipo`)

| Slug | Nome | Quando usar |
|---|---|---|
| `documento` | Documento | Texto entregue como relatório ou resposta de atividade (.docx, .pdf, .md). |
| `artigo` | Artigo | Texto de pesquisa ou resenha mais longo, com referências. |
| `codigo` | Código | Programas e scripts (.java, .pl, .py, .js...), geralmente com relatório junto. |
| `notebook` | Notebook | Jupyter Notebook com código, saída e explicação (.ipynb). |
| `simulacao` | Simulação | Dinâmica ou ambiente simulado, com evidências da execução. |
| `teste-automatizado` | Teste automatizado | Casos de teste executados por ferramenta (previsto para outras matérias). |
| `material-de-estudo` | Material de estudo | Mapa mental, resumo ou interativo que montei para estudar. |
| `certificado` | Certificado | Comprovante de curso ou atividade extracurricular. |
| `sistema` | Sistema | Entrega de projeto maior, muitas vezes no repositório do projeto (arquitetura, dados, API, código). |

## Regras do vocabulário

- Um termo, um significado. Não uso sinônimos.
- Termos novos entram primeiro aqui, depois nas atividades.
- Slug sempre em minúsculas, sem acento e sem espaço.
